# CARO (베타)

캠핑장 예약이 **열리는 시각**을 날짜별로 찾아 주고, 구글 캘린더 알림과 예약 페이지로 연결하는 웹앱입니다. 예약을 대신하지 않습니다.

- 데이터: 캠핏·땡큐캠핑·그래가 공개 페이지(매일 새벽 갱신), 숲나들e·국립공원·서울시 공식 예약 규칙
- 파일: `index.html`(화면), `data.js`(매일 갱신 데이터), `pub.js`(공공 예약 규칙), `sw.js`(오프라인)
- 개인정보: 수집하지 않음 → [privacy.html](privacy.html)

베타 테스트용 비공개 배포입니다. 검색엔진 노출을 막아 두었습니다.
